# Metric semantics and admissible uses

`forget loss`, `retain loss` and `maxent loss` are preserved original TensorBoard labels. Their values are finite scalar aggregates emitted by the source writer. The exact objective, normalization, masking, cohort membership and producing source revision are not identified by these labels. In particular, the serialized GradDiffDualDatasetProvider target does not prove a gradient-difference objective; a saliency/maxent folder name does not prove the implementation of an entropy loss.

`validation` is a logged split label, not verified held-out membership or untouched-test performance. `ppl` is an original label. PPL_CONSISTENCY.csv pairs loss and ppl by source, tag, step and original invocation order and reports exp(loss) versus the original float32 ppl. Arithmetic agreement is only a consistency observation. It does not establish autoregressive NLL, valid-token aggregation, a biological task, evaluation independence or a compatible reference. Logged forget loss is not silently substituted for the precisely defined S09 benign LM NLL or classifier cross-entropy.

The configuration declares global_batch_size128/micro_batch_size16 and evaluation settings702/500 or1/1000 depending on family. These are declarations. Actual iteration completion, batching/rank averaging, loss masks, repeated-data behavior and unique denominator remain unknown. No eval_iters×batch estimate is used as sample count. ALTERNATE_AXIS_EQUIVALENCE.csv records observed step/sample counter and value correspondence; these paired displays are not independent observations.

Source-file SHA256 identifies a log byte stream, not an intervention run, checkpoint content, parent, cohort or replicate. Each observation ID binds sourceSHA:event-order:value-order. Reinit5 duplicate validations remain separate original records with unresolved invocation roles; no averaging, smoothing, last-value selection or derived uncertainty is performed. Three probe CV seeds remain probe sensitivity, not intervention replication.

`l2_norm/grad/...decoder.layers...` and finalnorm gradient tags are optimization diagnostics. A layer index in a tag does not turn gradient magnitude into layerwise forget-task performance. There are zero qualified layerwise forget-performance records.

Numeric source points are usable for labeled source quotations and descriptive traces. They are not admitted scientific aggregate measurements until metric/cohort/protocol identity is qualified. Exact checkpoint-matched comparisons additionally require the log invocation to be bound to delivered tensor content. References require compatibility with the actual target task/cohort/split/protocol/readout, not only self-consistent advertised reference fields. Missing uncertainty remains missing and does not erase an otherwise valid source point; an interval is never manufactured from successive steps or repeated calls.

Source numeric direction is unresolved. No checkpoint ranking, optimum dose, causal selectivity or successful-unlearning conclusion is authorized by the observed traces. Separate retain and forget task/cohort semantics must remain explicit in any future legitimate combined view. Whole-model measurements must never be expanded into26 independent layerwise measurements.
