# CPU execution and independent checking

H3 uses committed serial fitter65e6942 with four BLAS threads. Its source and outputs remain unchanged. Later five-task fitting may use fit_multiretain_parallel.py: four independent CV-fold workers, each restricted to one BLAS thread, and a one-thread final refit after workers finish. Maximum scientific CV CPU budget remains four threads. The parent also uses one numerical thread to avoid idle thread-pool overhead. Same data, fold IDs, candidate C values, original balanced LBFGS/tolerance/convergence retry, training-only selection and fixed-base policy. Parallelism changes scheduling, not the scientific selection budget or endpoint. Worker CPU time and parent CPU time are recorded separately; worker setup is accounted through child usage at shutdown. Source identity differs explicitly.

Independent audit uses pairwise positive-vs-negative wins for AUROC and score-threshold indicator matrices for AP, separately from the producer's cumulative tied-rank implementation. Saved scaler/head algebra is reconstructed without sklearn prediction methods. Synthetic binary/multiclass tie/missing-class and saved-head reconstruction checks passed. Full production validation will require complete group receipts, exact IDs/labels/groups/hashes, all folds/C accounting, all prediction/probability metrics and every paired resample, plus separately aggregated causal NLL/PPL. No independent GPU replication or CV refitting is claimed.

Verification tolerances: probabilities1e-10 absolute; scalar metrics/paired draws/intervals1e-12 absolute; scaler means rtol1e-10/atol1e-12, variances rtol1e-9/atol1e-12. These derive from saved float32 feature transforms and float64 head/accounting precision and are set before running the production auditor.

A temporary four-core affinity placement during H3 reduced observed throughput (~28s to~117s/unit) on this shared host. Normal scheduling was restored; four-thread numerical-library limits remained. Both scheduling receipts and all actual CPU usage are preserved. This did not change data, fitting settings or outputs.
