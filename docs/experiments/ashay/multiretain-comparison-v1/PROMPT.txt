- AUROC.
- Accuracy.
- Balanced accuracy.
- Average precision.
- Classifier cross-entropy where already defined.

multiclass definitions. Splice AUROC is macro one-vs-rest. Biological label
names require evidence from the identity audit.

Compute causal NLL/PPL through the validated actual LM output head:
- Correct next-token alignment and target mask.
- Per-sequence loss sums and valid-target counts.
- Aggregate NLL = total loss / total valid targets.
- PPL = exp(aggregate NLL).

causal LM loss.
