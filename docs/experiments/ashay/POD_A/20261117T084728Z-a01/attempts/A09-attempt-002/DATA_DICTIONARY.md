# Integrated release data dictionary

TABLE_INDEX.json enumerates every canonical shard and exact union counts. SOURCE_TABLE_INDEX.json lists immutable committed source tables, their full original column lists, file hashes and row counts. Each canonical row retains a full-precision compact view plus source_id, header-based CSV line, file hash and canonical original-row hash. This lossless-by-reference design preserves every original scientific/status/provenance field without repeating large producer tables. Use git show <source_commit>:<source_table> to obtain exact originals; do not parse rounded report text as data.

A09_row_id preserves an existing logical_id. Historical rows lacking one receive legacy-v1 IDs from the complete scientific context and effective tensor identities, with no outcome values in identity. A09_scientific_key_sha256 is a separate bijective scientific-context key. The original content fields and source status remain unchanged; A09_effective_content_id and A09_effective_release_status supply approved identity/release overlays. R3’s original empty field is preserved. Measurements, ingestion, audit, ancestry and exposure are separate.

Kinds:classifier_marginal, classifier_paired, LM_marginal, LM_paired. Classifier rows retain checkpoint/reference, task, split, representation, CV seed, policy, source/reference policies and metric. LM has no layer/CV axis. Six current checkpoints ×seven reporting domains ×two LM metrics =84marginals; six H3 test domains are previously examined exploratory. All dev results retain exploratory pointwise uncertainty.

Estimate and CI fields retain original decimal strings. Empty CSV means null, never zero; original missing-CI reasons remain. Paired effects are target minus matched reference. Higher AUROC/AP/accuracy/balanced accuracy is favorable; lower classifier CE/NLL/PPL is favorable. Perplexity is exp(corpus NLL), not independent evidence. Policy gaps are descriptive points with no new interval family.

Typed NPZ-file hashes, probability-array hashes, LM sufficient-statistics files and sealed historical feature-bundle selectors describe different objects; join them through their immutable source/provenance registries, not raw digest equality. Historical canonical control aliases reuse A09-attempt-001’s exact task/split/seed/content/prediction-qualified map. Complete source values and typed references remain in the immutable indexed originals.

Head/application/control/LM counts are different denominators. A CV seed is probe-selection sensitivity, not a checkpoint-training replicate. H3 exploratory test adds reporting records, not fitted heads. TRAIN LM diagnostics are excluded. R2 missingness remains explicit with no interpolated points.
